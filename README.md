# Data Science Learning Vault

Repositorio personal de estudio, notas teóricas, experimentación en código y tutoriales guiados.

## Estructura
- **01_python_and_code/**: Fundamentos de programación, estructuras de datos y algoritmos.
- **02_math_and_stats/**: Notas y notebooks de cálculo, álgebra lineal, probabilidad e inferencia estadística.
- **03_data_and_ml/**: Manipulación de datos (Pandas/NumPy), visualización y machine learning.
- **04_tutorials/**: Proyectos prácticos y tutoriales externos (code-alongs).
- **05_cheatsheets/**: Snippets rápidos, fórmulas y comandos de consulta frecuente.
